## 1. 一句话定位

**FuncGNN 是面向 And-Inverter Graph（AIG）电路表示学习的下一代 GNN：用「Hybrid Feature Aggregation（GraphSAGE + GINConv 交替）+ Global Context Normalization（用 AND-to-NOT 边比驱动条件缩放的 gate-aware normalization）+ Multi-Layer Integration（跨所有层 dense 拼接 + 线性融合）」三件套，针对 AIG 的两大结构异质性挑战（拓扑异质 + 全局逻辑信息丢失）做架构级定制，在 ITC'99/IWLS'05/EPFL/OpenCore 四套 9,933 个 AIG 子电路上，把信号概率预测（SPP）MAE 从 PolarGate(L=9) 的 0.0097 降到 0.0095（-2.06%）、真值表距离预测（TTDP）MAE 从 0.2272 降到 0.1847（-18.71%），同时训练时间减少 50.6%、GPU 显存减少 32.8%。**

这句话里的七个技术承重点，后面逐一拆解：

1. **「AIG 上的功能语义」问题域定位** — AIG（AND-Inverter Graph，与-非图）是逻辑综合和形式验证的事实标准中间表示（ABC、yosys、Synopsys DC 全部用它）。已有 GNN 方法（DeepGate、DeepGate2、DeepGate3、PolarGate、HOGA）只学**结构特征**——节点类型、邻居分布。FuncGNN 的目标是把「这个子电路输出 1 的统计概率（signal probability）」和「这个子电路的功能跟另一个子电路有多相似（truth-table distance）」这种**功能标签**学到节点/图嵌入里。
2. **挑战 1：Structural Heterogeneity（结构异质性）** — AIG 的拓扑多样：规模从几十节点到几千节点、逻辑深度从 3 层到 24 层、AND/NOT 比例从 0.90 到 30.4（EPFL 子电路）。这种分布的剧烈变动让标准 GNN 的消息传递不稳定。FuncGNN 的 Hybrid Aggregation + Global Normalization 联合解决。
3. **挑战 2：Global Information Loss（全局信息丢失）** — 现有 GNN 是局部消息传递，但 AIG 的功能等价性依赖**长程结构信息**（两个 AIG 结构完全不同却布尔等价）。FuncGNN 用 Multi-Layer Integration（dense 拼接所有中间层）显式合成全局信息，绕开 attention 的高计算成本。
4. **Hybrid Feature Aggregation（混合特征聚合）** — GraphSAGE 的均值聚合擅长捕捉拓扑分布，GINConv 的求和聚合（带可学习 ε）擅长区分多集结构。FuncGNN 让两者交替：每层先 GraphSAGE（+ NOT 边符号反转）再做 GINConv + MLP，叠加 GELU + Dropout(0.1)。这比纯 GIN 或纯 SAGE 都更稳定。
5. **Global Context Normalization（全局上下文归一化）** — 拿电路级的 AND-to-NOT 边比 r 作为全局先验，把它和标准 GraphNorm 的 γ、β 做条件缩放：$\gamma_{dyn} = W_1 \gamma r + b_{1\gamma}$。这等价于条件 BatchNorm / FiLM 的做法——让归一化参数随电路的「门分布」自适应，避免「NOT 主导电路」和「AND 主导电路」共用同一组归一化参数带来的训练抖动。
6. **Multi-Layer Integration（多层集成）** — 把所有 K 层的中间嵌入 dense concat 后过一个线性层 $W_{fuse}$，再接 MLP head。这避免了 attention 的 $O(n^2)$ 复杂度，又让最浅层（局部）和最深层（全局）的特征都参与最终预测。消融证明移除该组件 SPP MAE 暴涨 142%。
7. **训练数据稀缺下的稳定学习** — 论文特别强调 SPP/TTDP 标签生成昂贵（每电路要 ≤100k 次随机逻辑仿真），所以训练集仅 5%，测试集 90%（0.05/0.05/0.9 划分）。FuncGNN 在这个「极小训练、极大测试」的困难设置下，10 个 random seed 的 SPP MAE IQR 仅 0.000175（96.92% 低于最佳 DeepGate 变体）——稳定性是其重要卖点。

## 3. 输入 / 输出

### 3.1 输入

**(a) And-Inverter Graph（AIG）**

AIG 是 FuncGNN 的唯一图输入格式。它只有两种功能节点：**PI（Primary Input，主输入）** 和 **2 输入 AND**，外加边上标注的 NOT 取反标记（NOT 不是独立节点，而是边属性）。AIG 的好处是任何组合逻辑电路（Verilog、BLIF、BENCH）都可以通过 ABC 等工具无损转换为 AIG。

**最小 AIG 示例**：`y = (a & b) | c` 用 De Morgan 转 AIG 后：

```text
节点（4 个）：
  PI_1: a
  PI_2: b
  PI_3: c
  AND_4: a & b              (fanin={PI_1, PI_2})
  NOT_5: !(a & b)           (fanin={AND_4}, 边标 invert)
  NOT_6: !c                 (fanin={PI_3}, 边标 invert)
  AND_7: !(a&b) & !c        (fanin={NOT_5, NOT_6})
  NOT_8: y = !(AND_7)       (fanin={AND_7}, 边标 invert)
```

**边表示**：FuncGNN 的边张量 $E \in \mathbb{Z}^{2 \times |E|}$，每个边携带符号 $s \in \{-1, +1\}$，$+1$ 表示正常 AND 边，$-1$ 表示 NOT（取反）边。

**(b) 节点初始特征**

One-hot 节点类型 + 可选位宽信息。论文用节点类型 one-hot 编码（包括 Input/Output/AND/NOT/各种组合单元，具体类型数取决于 AIG 综合后的实际节点种类）。

**(c) 全局先验：AND-to-NOT 边比**

整个电路统计的「AND 边数 / NOT 边数」比值 $r$，作为 Global Context Normalization 的条件输入。

**(d) SPP / TTDP 标签（训练阶段）**

- **SPP 标签**：对每个非 PI 节点 $v$，跑 ≤100k 次随机输入向量仿真，统计 $v$ 输出为 1 的频率作为 ground truth $y_v$。
- **TTDP 标签**：对每对子电路 $(A, B)$，计算它们真值表的归一化 Hamming 距离（Eq.18-19）作为距离 ground truth。

### 3.2 中间产物

**(a) 节点嵌入 $h_v^{(k)}$**

经过 FuncGNN 第 $k$ 层后，每个节点得到一个 256 维向量。包含「邻居聚合的局部信息 + 门分布归一化后的全局信息」。

**(b) 图级嵌入 $h_G$**

$h_G = \text{Mean}(\{h_v^{(L)}\}) + \text{Max}(\{h_v^{(L)}\})$

Mean 捕获整体特征，Max 捕获最显著特征。

**(c) 跨层 dense 嵌入 $h_v^{dense}$**

$h_v^{dense} = W_{fuse} \cdot \text{concat}(h_v^{(1)}, h_v^{(2)}, \ldots, h_v^{(L)}) + b_{fuse}$

这是 Multi-Layer Integration 的关键中间产物——把每一层的局部/全局特征都融合到一个向量。

### 3.3 输出

**(a) Signal Probability Prediction（SPP）**

每个节点 $v$ 输出一个标量 $\hat{y}_v \in [0, 1]$，表示该节点输出为 1 的预测概率。

**(b) Truth-Table Distance Prediction（TTDP）**

每对子电路输出一个标量 $\hat{d}(A, B) \in [0, 1]$，表示它们功能差异的归一化距离。

## 4. 方法与架构

### 4.1 整体 Pipeline

```text
                            FuncGNN 整体架构
   ═══════════════════════════════════════════════════════════

   输入：
   ┌──────────────────────────────────────────────────────────┐
   │ AIG 图 G = (V, E)                                         │
   │   X: N × d_in 节点特征矩阵                                 │
   │   E: 2 × |E|  边索引                                       │
   │   s: |E|      边符号 (+1=AND, -1=NOT)                      │
   │   r: 全局 AND-to-NOT 边比 (scalar)                        │
   └──────────────────────────┬───────────────────────────────┘
                              │
                              ▼ (Linear Projection)
   ┌──────────────────────────────────────────────────────────┐
   │ X_trans = W X     (Eq. 2)                                 │
   └──────────────────────────┬───────────────────────────────┘
                              │
        ┌─────────────────────┴─────────────────────┐
        │  Loop for L layers (default L=3):          │
        │  ┌──────────────────────────────────────┐ │
        │  │ GraphSAGE Agg (Eq. 5-6):             │ │
        │  │   h_v^agg = (1/|N(v)|) Σ s(e_vj) X_j │ │
        │  │   + h_v_skip                          │ │
        │  │   → GELU + GraphNorm (global ctx)    │ │
        │  │   → Dropout 0.1                       │ │
        │  ├──────────────────────────────────────┤ │
        │  │ GINConv Enhance (Eq. 8):              │ │
        │  │   h_v ← (1+ε) h_v + Σ h_u            │ │
        │  │   → MLP (2 Linear + ReLU)            │ │
        │  └──────────────────────────────────────┘ │
        │  ↑ 每层都套 Global Context Normalization   │
        └─────────────────────┬─────────────────────┘
                              │
                              ▼ (Multi-Layer Integration)
   ┌──────────────────────────────────────────────────────────┐
   │ h_v^dense = W_fuse · concat(h_v^(1),...,h_v^(L)) + b_fuse │
   │   ↑ Eq. 13，全层 dense 拼接                              │
   └──────────────────────────┬───────────────────────────────┘
                              │
                              ▼ (Readout)
   ┌──────────────────────────────────────────────────────────┐
   │ Readout MLP:                                              │
   │   LayerNorm + Linear + Dropout + ReLU                     │
   │   + Linear + Dropout + Sigmoid → ŷ_v                     │
   └──────────────────────────┬───────────────────────────────┘
                              │
                              ▼
   ┌──────────────────────────────────────────────────────────┐
   │ 输出: SPP 预测 ŷ_v ∈ [0,1]                               │
   │       或 TTDP 预测 d̂(A,B) ∈ [0,1]                       │
   └──────────────────────────────────────────────────────────┘
```

### 4.2 核心模块逐个详解

#### 模块 1：Hybrid Feature Aggregation（混合特征聚合）

**做什么**：在每一层交替使用 GraphSAGE 风格的均值聚合 + GINConv 风格的求和+MLP 增强。

**为什么这样设计**：

GraphSAGE 的均值聚合擅长「捕捉拓扑分布的统计量」，但单射性弱（两个不同邻居多集可能聚合到同一均值）。GINConv 的 $(1+\varepsilon)h_v + \sum h_u + \text{MLP}$ 形式被 [Xu et al. ICLR 2019] 证明具有**最强单射性**——可以区分任意不同的邻居多集，但参数更多、更容易过拟合。

FuncGNN 让两者交替：先 GraphSAGE 把拓扑分布聚合到节点，再 GINConv 做非线性精炼。这类似 ResNet 的 identity + conv 组合——GraphSAGE 是 identity，GINConv 是 conv。

**关键公式**（Eq. 4-8）：

**消息构造（Eq. 4）**：

$$
m_j(v) = s(e_{vj}) \cdot X_{trans, j}
$$

- $s(e_{vj}) \in \{+1, -1\}$：边的 NOT 符号。NOT 边的消息直接取反——这是 AIG 表示的关键，因为 AND + 取反标记完整编码了所有布尔逻辑。

**GraphSAGE 聚合（Eq. 5-6）**：

$$
h_v^{agg} = \frac{1}{|N(v)|} \sum_{j \in N(v)} m_j(v) + h_v^{skip}
$$

$$
h_v^{(k+1)} = \text{Dropout}\left( \sigma \left( \text{Norm}(r, h_v^{(k)} + h_v^{agg}) \right) \right)
$$

- $h_v^{skip}$：self-loop（论文 Eq.3 给每个节点加自环 +1）
- $\sigma$：GELU 激活
- $\text{Norm}(r, \cdot)$：Gate-Aware GraphNorm（见模块 2）

**GINConv 增强（Eq. 8）**：

$$
h_v^{(k+1)} = (1 + \varepsilon) \cdot h_v^{(k)} + \sum_{u \in N(v)} h_u^{(k)}
$$

$$
h_v^{(k+1)} = \text{MLP}^{(k)}\left( h_v^{(k+1)} \right),\quad \text{MLP}(x) = W_4 \cdot \sigma(W_3 x + b_3) + b_4
$$

- $\varepsilon$：可学习标量
- $\sigma$：ReLU
- MLP 是 2 层 Linear + ReLU

**输入/输出**：

- 输入：节点特征矩阵 + 边 + 边符号 + 全局比 r
- 输出：第 k 层节点嵌入 $\{h_v^{(k)}\}$

#### 模块 2：Global Context Normalization（Gate-Aware Normalization）

**做什么**：在 GraphNorm 基础上，把全局 AND-to-NOT 边比 $r$ 作为条件信号注入到缩放因子和偏置。

**为什么这样设计**：

AIG 的 NOT 边比例在不同电路中差异极大（ITC'99 平均 ~30%，EPFL 部分电路 4% 以下，IWLS 部分 50%+）。如果所有电路共用同一组 $(\gamma, \beta)$ 归一化参数，NOT-heavy 电路和 AND-heavy 电路的训练分布会互相拉扯，导致收敛慢、性能低。

借鉴 [Conditional BatchNorm / FiLM (Perez et al. 2018)] 的思想，把 $r$ 当成条件：

**Eq. 9-12**：

$$
h^{std}_v = \frac{h_v - \mu}{\sigma} \quad \text{(per-feature standard score)}
$$

$$
\gamma_{dyn} = W_1 \cdot \gamma \cdot r + b_{1\gamma},\quad \beta_{dyn} = W_2 \cdot \beta \cdot r + b_{2\beta}
$$

$$
\gamma = \gamma_0 + \gamma_{dyn},\quad \beta = \beta_0 + \beta_{dyn}
$$

$$
h^{norm}_v = h^{std}_v \odot \gamma + \beta
$$

- $W_1, W_2$：可学习线性投影
- $\gamma_0, \beta_0$：标准 GraphNorm 的可学习参数
- $r$：整个电路的 AND-to-NOT 比（scalar）

**工程直觉**：当 $r$ 大（AND-heavy），$\gamma$ 偏向放大 AND 节点信号；当 $r$ 小（NOT-heavy），$\gamma$ 偏向保留 NOT 信号。这种**电路自适应的归一化**让模型对门分布变化不敏感。

**输入/输出**：

- 输入：节点嵌入 $h_v$ + 全局比 $r$
- 输出：归一化嵌入 $h_v^{norm}$

#### 模块 3：Multi-Layer Integration（多层集成）

**做什么**：把所有 L 层的中间嵌入 dense concat，过一个线性层融合。

**为什么这样设计**：

标准 GNN 只用最后一层嵌入 $\{h_v^{(L)}\}$，但浅层捕获局部特征（单跳邻居）、深层捕获全局特征（多跳路径）。AIG 上的功能等价性（TTDP）需要长程推理，仅用最后一层会丢失浅层局部信息。

但 attention 的 $O(n^2)$ 在大电路上太贵，residual 加法会模糊层间差异。Dense concat 是 O(n) 且不模糊——所有层的信息都保留，再让 $W_{fuse}$ 学一个最优的线性组合。

**关键公式**（Eq. 13）：

$$
h_v^{dense} = W_{fuse} \cdot \text{concat}\left( h_v^{(1)}, h_v^{(2)}, \ldots, h_v^{(L)} \right) + b_{fuse}
$$

- $W_{fuse} \in \mathbb{R}^{d \times (L \cdot d)}$：融合线性层
- $L$：默认 3（论文也实验 L=1, 3, 5, 7, 9）

**消融证据**（论文 Table 4）：移除 Multi-Layer Integration，SPP MAE 暴涨 142.11%，TTDP MAE 暴涨 89.01%——这是三个组件里贡献最大的。

**输入/输出**：

- 输入：所有层嵌入 $\{h_v^{(1)}, \ldots, h_v^{(L)}\}$
- 输出：融合嵌入 $h_v^{dense}$

#### 模块 4：Readout MLP（图级 / 节点级读出）

**SPP 用节点级读出**（每个节点独立预测 $\hat{y}_v$）：

$$
\hat{y}_v = \text{Sigmoid}\left( W_2 \cdot \text{Dropout}\left( \text{ReLU}\left( \text{LayerNorm}(W_1 h_v^{dense} + b_1) \right) \right) + b_2 \right)
$$

**TTDP 用图级读出**（对子电路对求图级嵌入后做差 + MLP 预测距离）：

$$
h_G = \text{Mean}(\{h_v^{dense}\}) + \text{Max}(\{h_v^{dense}\})
$$

$$
\hat{d}(A, B) = \text{MLP}_{dist}(|h_{G_A} - h_{G_B}|)
$$

| 模块 | 输入 | 输出 | 用的模型/工具 | 是否需训练 |
|---|---|---|---|---|
| AIG Preprocessor | Verilog/BLIF/BENCH | AIG (X, E, s) | ABC / yosys | 否（工具链） |

## 5. 关键公式

### 5.1 Message Construction（带 NOT 符号的消息）

$$
m_j(v) = s(e_{vj}) \cdot X_{trans, j}
$$

- $m_j(v)$：从节点 $j$ 传给节点 $v$ 的消息
- $s(e_{vj})$：边 $e_{vj}$ 的符号，$+1$ 表示正常 AND，$-1$ 表示 NOT 取反
- $X_{trans, j}$：节点 $j$ 经线性投影后的特征

**工程直觉**：在 AIG 里，「与门 + 边上画一个小圈」就完整表达了所有布尔运算。这个公式让消息传递直接吃掉 NOT 标记——遇到 NOT 边就自动把邻居特征取反。这避免了把 NOT 也做成独立节点带来的图结构复杂化。

**为什么这么设计**：相比 DeepGate/DeepGate2 把 NOT 当成独立节点处理，FuncGNN 的 NOT-as-edge 设计让图更稀疏（节点数更少），消息传递更高效。

### 5.2 Hybrid Aggregation（GraphSAGE + GINConv 交替）

$$
h_v^{agg} = \frac{1}{|N(v)|} \sum_{j \in N(v)} m_j(v) + h_v^{skip}
$$

$$
h_v^{(k+1)} = \text{Dropout}\left( \sigma\left( \text{Norm}(r, h_v^{(k)} + h_v^{agg}) \right) \right) \quad \text{(SAGE 阶段)}
$$

$$
h_v^{(k+1)} = (1 + \varepsilon) \cdot h_v^{(k)} + \sum_{u \in N(v)} h_u^{(k)} \quad \text{(GINConv 阶段)}
$$

$$
h_v^{(k+1)} = \text{MLP}^{(k)}(h_v^{(k+1)}) \quad \text{(MLP 增强)}
$$

- $\sigma$：GELU（SAGE 阶段）/ ReLU（GINConv 阶段）
- $\varepsilon$：GINConv 的可学习标量
- $\text{Norm}(r, \cdot)$：Gate-Aware Normalization

**工程直觉**：两阶段级联类似 ResNet——SAGE 提供稳定的 identity baseline，GINConv 在它之上做非线性精炼。如果只用 SAGE，聚合函数不是单射的（不同拓扑可能产生相同均值）；如果只用 GINConv，参数量大且容易过拟合。

**为什么这么设计**：消融证明（论文 Table 4）把 SAGE 换成 GCN（另一种均值聚合变体），SPP MAE 增加 87.37%、TTDP MAE 增加 81.97%——证明 SAGE 的均值聚合在 AIG 上比其他 GCN 变体更合适。

### 5.3 Gate-Aware Normalization（条件缩放）

$$
h^{std}_v = \frac{h_v - \mu}{\sigma}
$$

$$
\gamma_{dyn} = W_1 \cdot \gamma \cdot r + b_{1\gamma}
$$

$$
\beta_{dyn} = W_2 \cdot \beta \cdot r + b_{2\beta}
$$

$$
\gamma = \gamma_0 + \gamma_{dyn}, \quad \beta = \beta_0 + \beta_{dyn}
$$

$$
h^{norm}_v = h^{std}_v \odot \gamma + \beta
$$

- $\mu, \sigma$：每 batch / 每图的 per-feature 均值与标准差
- $\gamma_0, \beta_0$：标准 GraphNorm 的可学习参数
- $W_1, W_2$：从全局比 $r$ 生成条件偏移的线性层
- $r$：电路级 AND-to-NOT 边比

**工程直觉**：当电路 NOT-heavy（$r$ 小）时，$\gamma_{dyn}$ 会偏向放大负信号以补偿；AND-heavy 时反过来。这是一种 **feature-wise linear modulation (FiLM)** 思想，让归一化层「感知」电路的整体门分布。

**为什么这么设计**：AIG 的门分布异质性巨大（NOT 占比 4%~50%），固定 $(\gamma, \beta)$ 必然导致部分电路欠拟合、部分过拟合。条件归一化让模型对所有电路类型保持稳定训练。

**消融验证**（论文 Table 4）：把 Gate-Aware Norm 换成普通 GraphNorm，TTDP MAE 涨 21.33%——证明全局上下文注入的价值。

### 5.4 Multi-Layer Integration（Dense Concat）

$$
h_v^{dense} = W_{fuse} \cdot \text{concat}\left( h_v^{(1)}, h_v^{(2)}, \ldots, h_v^{(L)} \right) + b_{fuse}
$$

- $W_{fuse} \in \mathbb{R}^{d \times L \cdot d}$：融合矩阵
- $b_{fuse} \in \mathbb{R}^d$：偏置

**工程直觉**：浅层 GNN 捕获「节点 v 是什么类型的门 + 直接邻居是谁」；中层捕获「v 在 2-hop 内处于什么子结构」；深层捕获「v 在电路中的全局角色（关键路径？冗余？）」。AIG 的功能等价性同时依赖这三层信息。

**为什么这么设计**：相比 attention 的 $O(n^2 d)$ 复杂度，dense concat 是 $O(nLd)$，在大电路上（EPFL/IWLS 部分电路 >3000 节点）优势巨大。论文 RQ4 实验证明 L=1 到 L=9 都能训练且性能稳定，没有 over-squashing 现象。

### 5.5 SPP Loss（L1 on Signal Probability）

$$
\text{Avg.Error}_{SPP} = \frac{1}{N} \sum_{v \in V} |y_v - \hat{y}_v|
$$

- $y_v$：节点 $v$ 输出为 1 的 ground-truth 频率（从 ≤100k 次随机逻辑仿真统计）
- $\hat{y}_v$：FuncGNN 的预测

**工程直觉**：用 L1 而不是 L2，是因为 SPP 的目标分布近似均匀（在 0.5 附近密集），L2 对极端值过敏感。L1 给所有误差等权，训练更稳定。

**为什么这么设计**：SPP 标签是 [0, 1] 区间连续值，本质是回归。L1（MAE）对离群点鲁棒，适合标签分布有噪声的蒙特卡洛仿真结果。

### 5.6 TTDP Loss（L1 on Truth-Table Distance）

真值表距离的两个等价定义（Eq. 16-19）：

**定义 1：归一化 Hamming 距离**

$$
d_{H}(A, B) = \frac{1}{2^n} \sum_{x \in \{0,1\}^n} |\text{TT}_A(x) - \text{TT}_B(x)|
$$

- $\text{TT}_A(x)$：子电路 $A$ 在输入 $x$ 下的真值表输出

**定义 2：基于余弦相似度的嵌入距离**

$$
d_{cos}(A, B) = 1 - \cos(h_A, h_B)
$$

两种都 zero-normalize 到 $[0, 1]$。FuncGNN 用 MLP 预测 $d_{cos}$。

**工程直觉**：用「嵌入距离」而非直接预测 Hamming 距离，是因为子电路对数 $O(N^2)$ 远小于「枚举所有 $2^n$ 输入 pattern」的指数复杂度。学习嵌入距离是 O(N^2) 的回归任务，可扩展。

**为什么这么设计**：嵌入空间中的距离可迁移到下游——比如用 FuncGNN 嵌入做 k-NN 检索找出最相似的子电路，再做 SAT equivalence check。这是 verification acceleration 的核心套路。

## 7. 创新点

### 创新点 1：AIG 上的混合 GraphSAGE + GINConv 聚合

**和已有方法的关键区别**：

已有 [DeepGate2](../DeepGate2/论文深度讲解.md) 用高效单次传播 GNN（single-pass GNN design）、[PolarGate](https://github.com/BUPT-GAMMA/PolarGate) 用 GraphConv 加位置编码、DeepGate3 用 attention。FuncGNN 是第一个把 **GraphSAGE 均值聚合** 和 **GINConv 求和+MLP** 在 AIG 上**交替使用** 的工作。

为什么这个组合好？SAGE 的均值聚合对邻居分布统计量稳定，GINConv 的求和聚合对多集结构有单射性。两者交替既保留了 SAGE 的稳定性，又获得了 GIN 的判别力。这比 DeepGate3 的 attention-based 方法计算量小一个数量级（参数量 0.96M vs 8.56M，训练时间 3.02s vs 13.79s/epoch）。

### 创新点 2：Gate-Aware Conditional Normalization

**和已有方法的关键区别**：

已有电路 GNN 全部用普通 BatchNorm / LayerNorm / GraphNorm。FuncGNN 第一个把**电路级全局特征**（AND-to-NOT 边比）作为条件信号注入到归一化参数。这是 [FiLM (Perez et al. 2018)] 思想在电路 GNN 上的首次应用。

消融验证（Table 4）：把 Gate-Aware Norm 换成普通 GraphNorm，TTDP MAE 涨 21.33%。证明电路级异质性必须被显式建模，否则模型对门分布变化过敏感。

### 创新点 3：Multi-Layer Integration 解决 over-squashing

**和已有方法的关键区别**：

GNN 深度的瓶颈是 **over-squashing**（[Alon & Yahav 2020]）——随着层数加深，远距离节点的信息被压缩到固定维度的瓶颈里，丢失。AIG 的功能等价性需要长程推理，所以这个问题对电路 GNN 特别严重。

FuncGNN 用 dense concat 所有层中间嵌入 + 线性融合 $W_{fuse}$，把「over-squashing」问题转化为「层间特征融合」问题。论文 RQ4 验证：L=9 时性能仍然提升（没有 over-squashing 退化），且参数仅 0.96M，比 PolarGate(L=9) 的 0.98M 更少。

相比之下，DeepGate3 用 attention 缓解 over-squashing，但 attention 计算量是 $O(n^2)$，在 3000 节点大电路上很慢。

### 创新点 4：极小训练集（5%）下的稳定学习

**和已有方法的关键区别**：

论文 0.05/0.05/0.9 的划分（5% 训练、5% 验证、90% 测试）模拟了工业现实中**标签昂贵但推理时需要全图**的场景。在这个困难设置下：

- FuncGNN SPP MAE IQR 仅 0.000175
- 比最佳 DeepGate 变体低 96.92%

这种稳定性来自：(1) GraphNorm 的批量统计稳定；(2) Gate-Aware Norm 让不同门分布的电路共享参数；(3) Multi-Layer Integration 让浅层局部特征也能参与预测，不完全依赖深层全局推理。

## 10. 讨论与局限

### 10.1 论文自述的局限

1. **仅在四个公开 benchmark 上验证**（EPFL、ITC'99、IWLS'05、OpenCore）。论文承认「broader structural diversity remains untested」。
2. **没有理论证明 AND-to-NOT 边比作为全局先验能让模型获得「globally stable feature representations」**——这是经验性设计，缺理论。
3. **未在更下游的 EDA 任务**（logic synthesis、equivalence checking）上做端到端验证。论文只展示了 SPP/TTDP 两个中间任务的精度提升，没证明这些提升确实能加速综合。
4. **数据集规模有限**：9,933 子电路相比 DeepGate2/3 的训练集可能小一个数量级。

### 10.2 代码/复现层面的问题

1. **数据集依赖 PolarGate**：[FuncGNN GitHub](https://github.com/Vandbs/FuncGNN) 明确说明数据集从 [BUPT-GAMMA/PolarGate releases](https://github.com/BUPT-GAMMA/PolarGate/releases) 下载。所以严格地说 FuncGNN 是「在 PolarGate 数据集上做架构改进」。
2. **数据划分 0.05/0.05/0.9** 模拟稀缺标签，但这个划分是 ad hoc 的——不同 benchmark 的最优划分可能不同。
3. **TTDP 标签生成**依赖「ground truth 真值表距离」，这本身需要枚举 $2^n$ 输入 pattern（$n$ = 输入端口数）。论文说用「cosine-similarity-derived embedding distance」做近似，但具体计算方式在论文里没有完整 pseudocode。
4. **本地 PDF 文件 3779445_FuncGNN.pdf 内容不匹配**——实际是「Simulating Star Formation in the Aquila Rift」天文学论文。建议从 arXiv 2506.06787 下载正确的 PDF。

| 论点 | 评价 |
|---|---|
| **「比 PolarGate 强」** | 这是真的，但 PolarGate(L=3) 仅 0.0437 SPP MAE，FuncGNN 0.0095——主要差异来自 L=3 vs L=9 的层数。论文没控制变量做「同样 9 层」的对比，所以「Hybrid + Gate-Aware + Multi-Layer 三个组件的边际贡献」被「层数从 3 涨到 9」混淆了 |
| **「SPP MAE 0.0095 已经够低」** | 是的，<1% 误差对功耗估计来说基本够用。但 TTDP MAE 0.1847 还偏高——意味着预测的距离仍有 18% 平均误差，这对 LEC 候选筛选来说可能误判太多等价对 |
| **「极小训练集下的稳定性」** | 这是真正的卖点。5% 训练 + 10 random seeds 的 IQR 仅 0.000175，说明模型没有过拟合小样本。这是工业场景需要的——大多数公司没有百万级标注电路 |
| **「架构层面的 3 个创新叠加」** | 消融证明每个组件都有贡献，但「Multi-Layer Integration 单独贡献 142% MAE」远超其他两个（19%、87%）。这暗示真正起作用的是 dense concat + 线性融合，其他两个可能是「锦上添花」 |

## 12. 一分钟复述版

1. **问题**：AIG 电路表示学习要在「结构异质（拓扑差异大）+ 全局信息丢失（局部消息传递难捕捉长程等价性）」两大挑战下，提升 SPP / TTDP 任务精度。
2. **方法**：三组件架构——Hybrid Aggregation（SAGE + GINConv 交替）+ Gate-Aware Norm（用 AND-to-NOT 比做条件 GraphNorm）+ Multi-Layer Integration（dense concat 所有层 + 线性融合）。
3. **数据**：9,933 个 AIG 子电路（EPFL/ITC'99/IWLS'05/OpenCore），训练划分仅 5%，标签用 ≤100k 次随机逻辑仿真生成。
4. **训练**：Qwen3-8B 不参与——这是 GNN。Adam + lr=1e-3 + L1 loss + 256 hidden dim + L=3 默认层数。
5. **结果**：SPP MAE 0.0095（-2.06% vs PolarGate(L=9)），TTDP MAE 0.1847（-18.71%），训练时间减半，GPU 显存减 1/3。
6. **创新**：NOT-as-edge 设计 + 条件 GraphNorm + dense 跨层融合，分别对应结构异质和全局信息两大挑战。
7. **局限**：仅 4 个公开 benchmark、缺理论保证、未演示端到端 EDA 集成收益。
8. **位置**：EDA 17 阶段里的 ③逻辑综合辅助工具，与 [DeepGate](../DeepGate/论文深度讲解.md)、[DeepGate2](../DeepGate2/论文深度讲解.md) 同属电路表示学习家族。
