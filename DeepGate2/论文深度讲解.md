## 1. 一句话定位

**DeepGate2 是 DeepGate 的功能感知升级版——它发现了 DeepGate 的两个根本缺陷并逐项修复：缺陷一，logic-1 概率（signal probability）是一个统计量而非结构量，两个功能完全不同的门（如 AND(a,b) 和 NAND(a,b)）可以有相同的 logic-1 概率，导致 DeepGate 学到的 embedding 无法区分功能；缺陷二，因为所有 PI 初始 embedding 相同，DeepGate 被迫用 T=10 轮正反向传播来间接发现 reconvergence 结构，推理极慢。DeepGate2 的解决方案：把每个门的 embedding 显式拆为结构分支 hs（只编码连接关系）和功能分支 hf（编码布尔行为），用门对真值表的 Hamming 距离（而非单个门的概率）作为功能监督，给每个 PI 分配唯一正交初始向量作为"身份标识"，从而只需 1 轮前向传播即可完成全部信息传递。在相同 10,824 个子电路数据集上，概率预测误差降低 13.08%，推理速度提升 16.43 倍，等价门识别 F1-score 从 0.6778 跳到 0.9434；在逻辑综合下游任务中，SAT sweeping 的 SAT 调用减少 53.37%，总运行时间降低 49.46%；在 SAT 求解下游任务中，5 个 LEC 实例的平均求解时间减少 40.05%。**

这句话里的五个技术承重点，后面逐一拆解：

1. **从 signal probability 到 pairwise truth-table Hamming distance** -- 监督信号的根本升级。不再问"这个门的输出是 1 的频率是多少"，而是问"这两个门的真值表有多少位不同"。这使 embedding 空间中的距离正比于功能差异，可以区分概率相同但功能不同的门。
2. **hs/hf 双分支解耦** -- 每个门维护两套独立的 64 维向量。hs 只从 fanin 的 hs 聚合（纯粹的结构信息），hf 从 fanin 的 [hs, hf] 拼接聚合（结构为功能提供上下文）。这是"先知道怎么连，再知道算什么"的显式分层。
3. **PI Encoding（PIE）——给每个 PI 分配唯一身份证** -- 不同 PI 的结构初始向量 hs 是近似正交的（任意两个 PI 的点积接近 0）。这抹平了 DeepGate 的根本设计缺陷——所有 PI 初始 embedding 相同 → 必须多轮传播来间接区分。
4. **One-round GNN——从 10+10 轮到 1 轮** -- 因为 PI 有唯一标识，reconvergence 可以在单轮前向传播中通过 attention 被直接发现（"我的两个 fanin 追溯到同一组 PI"），不需要反向传播和多轮迭代。推理速度提升 16.43 倍。
5. **两阶段多任务训练 + 下游工具集成** -- Stage 1 先学简单的概率预测（让 hf 初步收敛），Stage 2 再加入功能距离损失和 reconvergence 损失。训练完成后，DeepGate2 以插件形式嵌入 ABC 逻辑综合工具和 CaDiCal SAT 求解器，实现端到端的运行时加速。

**覆盖率：2/17。** DeepGate2 与 DeepGate 处于相同的流程位置（逻辑综合后的门级表示层），但将"能做什么"从"学一个 embedding"推进到了"embedding 直接驱动下游工具加速"——它不再只是一个表示学习方法，而是有真实 EDA 工具集成和运行时收益的工程系统。

## 3. 输入 / 输出

### 3.1 输入

与 DeepGate 一致：统一转换为 AIG 格式的组合逻辑电路。但 DeepGate2 的数据准备增加了关键步骤——构造用于功能监督的 gate pair。

**数据准备流程**：

```text
原始电路 → ABC → AIG (.bench)
                      │
                      ▼
          ┌──────────────────────────┐
          │ 1. 解析 AIG 图结构        │
          │    - 节点: PI/AND/NOT     │
          │    - 边: fanin→gate       │
          │    - forward level        │
          └──────────┬───────────────┘
                     ▼
          ┌──────────────────────────┐
          │ 2. 逻辑仿真               │
          │    - PI≤13: 穷举完整真值表 │
          │    - PI>13: 15,000 随机   │
          │    - 每个 gate → 真值表向量│
          └──────────┬───────────────┘
                     ▼
          ┌──────────────────────────┐
          │ 3. 构造 gate pair 样本     │
          │    约束条件:               │
          │    ① 两 gate 共享同一组 PI │
          │    ② logic-1 概率差 ≤ 5%  │
          │    ③ 逻辑层级差 ≤ 5       │
          │    ④ Hamming 距离极端     │
          │       (<20% 或 >80%)      │
          │    输出: 894,151 pairs    │
          └──────────────────────────┘
```

**pair 采样约束的动机**：
- 约束①：如果两个 logic cone 不共享 PI，比较它们的真值表没有意义（变量空间不同）。
- 约束②：概率差太大 → 功能一定不同，属于"容易区分"的 pair，不需要浪费训练容量。
- 约束③：层级差太大 → 功能不太可能相关，同样属于低信息量 pair。
- 约束④：论文只采样"极相似"（<20% Hamming 距离）和"极不相似"（>80%）的 pair，中间地带的 pair 功能关系模糊，监督信号弱。

### 3.2 中间产物：PI Encoding（PIE）

这是 DeepGate2 最关键的中间表示创新。在消息传播开始之前，每个 PI 的结构初始向量 hs 被赋予一个唯一的"身份标识"：

```text
PI_1: hs_1 ≈ [ 1.0,  0.0,  0.0,  0.0, ...]  (64 维，模长≈1)
PI_2: hs_2 ≈ [ 0.0,  1.0,  0.0,  0.0, ...]
PI_3: hs_3 ≈ [ 0.0,  0.0,  1.0,  0.0, ...]
PI_4: hs_4 ≈ [ 0.0,  0.0,  0.0,  1.0, ...]
...

任意 PI_i · PI_j ≈ 0  (i ≠ j)
```

**工程直觉**：这相当于给每个 PI 发了一张"身份证"。在消息传播时，AND 门的 attention 聚合器看到 fanin 的 hs 向量后，可以通过点积判断"这两个 fanin 是否共享同一个 PI 来源"——不需要多轮迭代，单轮就能发现 reconvergence 结构。

所有 PI 的功能初始向量 hf 共享同一个可学习的向量（因为所有 PI 在随机仿真下 logic-1 概率均为 0.5，功能行为不可区分）。

### 3.3 最终输出

```text
hs[N, 64]: 结构嵌入 — 编码"怎么连"
hf[N, 64]: 功能嵌入 — 编码"算什么"
ŷ_prob[N, 1]: 每个 gate 的 logic-1 概率
ŷ_rc[P, 1]: 每对 gate 是否存在 reconvergence 关系
D_H(i,j) = 1 - cos(hf_i, hf_j): 任意 gate pair 的功能距离
```

**端到端例子**：以 DeepGate 使用过的 `y = (a&b)|c` 电路为例（3 个 PI，AIG 共 8 个节点），经过 DeepGate2 的单轮传播后：

```text
PI_a:  hs=[ 1.00, 0.00, 0.00,...]  hf=[ 0.05, 0.12,-0.08,...] (共享初始 hf)
PI_b:  hs=[ 0.00, 1.00, 0.00,...]  hf=[ 0.05, 0.12,-0.08,...]
PI_c:  hs=[ 0.00, 0.00, 1.00,...]  hf=[ 0.05, 0.12,-0.08,...]
AND_ab: hs=[ 0.33, 0.41,-0.15,...]  hf=[-0.23, 0.56, 0.31,...]  (ŷ=0.248)
NOT_ab: hs=[-0.12, 0.67, 0.22,...]  hf=[ 0.41,-0.33, 0.18,...]  (ŷ=0.752)
NOT_c:  hs=[ 0.15,-0.08, 0.91,...]  hf=[ 0.51, 0.02,-0.44,...]  (ŷ=0.498)
AND_n:  hs=[ 0.21, 0.34,-0.53,...]  hf=[-0.61, 0.11,-0.28,...]  (ŷ=0.373)
NOT_y:  hs=[-0.41, 0.18, 0.33,...]  hf=[ 0.77,-0.42, 0.09,...]  (ŷ=0.627)

功能距离示例:
  D_H(AND_ab, NOT_ab) ≈ 0.89  ← 功能相反 (AND vs NAND，Hamming 距离大)
  D_H(NOT_c, PI_c)   ≈ 0.91  ← 功能相反 (NOT vs 恒等)
  D_H(AND_ab, AND_n)  ≈ 0.52  ← 功能部分相关
```

## 4. 方法与架构

### 4.1 整体 Pipeline（对应论文 Figure 4）

```text
                   Circuit Netlist (.bench AIG)
                            │
                            ▼
  ═══════════════════════════════════════════════════════════════
  │  PI Encoding (PIE) —— 为每个 PI 分配唯一正交 hs 向量         │
  │  AND/NOT gate 的 hs, hf 初始化为零向量                       │
  ═══════════════════════════════════════════════════════════════
                            │
                            ▼
  ┌─────────────────────────────────────────────────────────────┐
  │  One-round Forward Propagation (Level 0 → Level max)         │
  │                                                              │
  │  For each level l:                                           │
  │    For each gate v at level l:                               │
  │                                                              │
  │    ┌─── 结构分支 (Structural Stream) ────────────────────┐  │
  │    │ hs_v = GRU_gatetype(                                  │  │

  │                                                              │
  │    ┌─── 功能分支 (Functional Stream) ─────────────────────┐  │
  │    │ hf_v = GRU_gatetype(                                  │  │
  │    │   hf_v,                                               │  │
  │    │   aggr_func({[hs_u, hf_u] | u ∈ fanin(v)})            │  │
  │    │ )                                                     │  │
  │    │ → 看 fanin 的结构+功能拼接                             │  │
  │    │ → AND / NOT 各有独立 aggregator + GRU                 │  │
  │    └──────────────────────────────────────────────────────┘  │
  │                                                              │

  │  Readout Heads                                               │
  │                                                              │
  │  Task 1: ŷ_prob[v] = MLP_prob(hf_v)          ← L1 loss       │
  │  Task 2: ŷ_rc[i,j] = MLP_rc([hs_i, hs_j])    ← BCE loss      │
  │  Task 3: D_H(i,j) = 1 - cos(hf_i, hf_j)      ← L1 loss       │
  │          (功能距离直接由 hf cosine 距离计算，无额外参数)       │
  └─────────────────────────────────────────────────────────────┘
                           │

  │  Two-stage Training                                          │
  │  Stage 1: w_prob=1, w_rc=0, w_func=0                         │
  │           → 先让 hf 学会 signal probability                  │
  │  Stage 2: w_prob=3, w_rc=1, w_func=2                         │
  │           → 加入 reconvergence + 功能距离监督                 │
  └─────────────────────────────────────────────────────────────┘
```

**这张图说明什么**：DeepGate2 的架构设计遵循一个清晰的原则——"结构是功能的脚手架"。结构分支 hs 先从 PI 的正交初始向量出发，通过纯结构聚合（只看连接关系）逐层传播，为每个门建立它在拓扑中的"位置感"。功能分支 hf 在同一轮传播中并行更新，但它看到的是 fanin 的 [hs, hf] 拼接——也就是说，hf 的更新依赖于 hs 已经提供的结构上下文。这种设计确保"AND 门在计算 a&b 时知道自己处于电路的哪个位置，从而能正确推断它的输出行为"。

### 4.2 核心模块逐个详解

#### 4.2.1 PI Encoding (PIE)：DeepGate 原罪的救赎

**这个模块存在的理由**：DeepGate 给所有 PI 分配相同的初始 embedding，导致模型无法区分不同 PI 的身份。图 1 直观展示了这个问题的后果：

```text
  电路结构:                       DeepGate 第 1 轮传播:
  PI_1 ──→ node4 ──→ node7       所有 PI 的 h^0 相同
    │                  ↑         → fanin(5) 的消息 = fanin(6) 的消息
    └──→ node5 ───────┘         → fanin(5')的消息 = fanin(6')的消息
                                 → 模型看不见"node5 和 node6 的 fanin 来自同一个 PI"
  PI_2 ──→ node4'──→ node7'
    │                  ↑         → 必须等第 2、3、... 轮传播，
    └──→ node5'───────┘           通过反向传播让 PI 的 embedding 产生差异
                                  → 需要 10+10=20 轮！
```

PIE 的解决方案：初始化时就让每个 PI 的 hs 向量唯一且正交。这样在第一轮前向传播中，node5 的 attention 聚合器就能"看到"PI_1 的 hs 向量通过两个不同的路径（PI_1→node4 和 PI_1→node5）都指向了 node7——reconvergence 结构被瞬间发现。

**为什么是正交向量**：正交意味着 $\text{hs}_i \cdot \text{hs}_j = 0$（$i \neq j$），即任意两个 PI 在结构嵌入空间中"最不相似"。这符合 PI 的物理语义——PI_1 和 PI_2 是两条完全独立的输入线，它们之间没有共享的物理来源。正交性是"独立"在向量空间中的最佳数学表达。

#### 4.2.2 结构分支 hs：纯拓扑信息流

**这个模块存在的理由**：电路的结构信息（"谁连到谁"）和功能信息（"算什么布尔函数"）本质上是两个不同层级的知识。一个 AND 门连到 PI_a 和 PI_b（结构事实）与它计算 a&b（功能事实）之间有关系，但不应混淆。结构分支让 hs 专注于编码拓扑位置——"我在电路图的什么位置"。

**聚合方式**（论文 Equation 6）：

$$
h_a^s = \text{aggr}_{\text{AND}}^s\left(\{h_j^s \mid j \in P(a)\}\right)
$$

$$
h_b^s = \text{aggr}_{\text{NOT}}^s\left(\{h_j^s \mid j \in P(b)\}\right)
$$

AND 和 NOT 各有独立的结构聚合器参数，因为它们的 fanin 结构含义不同（AND 有 2 个 fanin，NOT 有 1 个）。结构聚合器只看 fanin 的 hs。

#### 4.2.3 功能分支 hf：结构为功能的上下文

**这个模块存在的理由**：一个门的布尔输出不仅取决于 fanin 的布尔输出（功能），还取决于 fanin 之间是否存在 reconvergence（结构）——如果两个 fanin 都来自同一个 PI，它们的值不是独立的，AND 门的输出概率就不是 $0.5 \times 0.5 = 0.25$。

**聚合方式**（论文 Equation 7）：

$$
h_a^f = \text{aggr}_{\text{AND}}^f\left(\{[h_j^s, h_j^f] \mid j \in P(a)\}\right)
$$

$$
h_b^f = \text{aggr}_{\text{NOT}}^f\left(\{[h_j^s, h_j^f] \mid j \in P(b)\}\right)
$$

关键设计：功能聚合器的输入是 fanin 的 **hs 和 hf 拼接向量**。这使 attention 机制可以同时考虑"这个 fanin 在电路的什么位置"（hs）和"这个 fanin 算什么函数"（hf）来决定其重要性。

**为什么 AND 的功能聚合需要 hs，而 NOT 不需要**：NOT 只有一个 fanin，没有"两个 fanin 是否独立"的问题。AND 有两个 fanin，必须知道它们是否来自同一 PI（reconvergence）才能准确计算输出概率。这就是为什么 AND 的功能聚合输入是 [hs, hf]，而 NOT 的功能聚合只需要 hf。

**Attention 聚合器的实现**（论文 Equation 5，对所有四种聚合器通用）：

$$
\alpha_j = \text{softmax}\left(\frac{w_q^\top h_i \cdot (w_k^\top h_j)^\top}{\sqrt{d}}\right)
$$

$$
m_j = w_v^\top h_j
$$

$$
h_i^{\text{new}} = \sum_{j \in P(i)} (\alpha_j \cdot m_j)
$$

其中 $w_q, w_k, w_v$ 是可学习的 Q/K/V 投影矩阵，$d=64$ 是 embedding 维度。这是标准的 scaled dot-product attention（Transformer 风格），但用于 fanin→gate 的消息聚合而非序列元素之间的交互。直觉上：当前 gate 的 query（"我需要什么样的输入"）与 fanin 的 key（"我能提供什么"）匹配，匹配度决定 attention 权重。

#### 4.2.4 两阶段训练策略：课程学习的应用

**这个模块存在的理由**：如果直接从随机初始化开始同时训练三个 loss（概率 + reconvergence + 功能距离），三个任务会互相干扰——特别是功能距离损失 L_func 涉及 gate pair 的 Hamming 距离比较，在 hf 还没学会基本的概率表示之前，这种细粒度的功能比较几乎无法提供有效梯度。

**Stage 1（只学概率）**：
- $w_{\text{prob}}=1, w_{\text{rc}}=0, w_{\text{func}}=0$
- 目标：让 hf 学会"这个门的 output 倾向于 1 还是 0"
- 这是最简单的任务（单门标量回归），快速收敛

**Stage 2（全任务）**：
- $w_{\text{prob}}=3, w_{\text{rc}}=1, w_{\text{func}}=2$
- 从 Stage 1 的 checkpoint resume
- 加入 reconvergence 预测（需要结构理解）和功能距离学习（需要细粒度功能比较）

消融实验证明这种 staged training 是必须的：无 multi-stage 的模型 F1-score 只有 0.7137，而 multi-stage 达到 0.9434。L_func 从 0.1224 降到 0.0594（降低 51.47%）。

### 4.3 模块职责矩阵

| 模块 | 输入 | 输出 | 用到的模型/工具 | 是否需训练 |

| TFMLP 功能聚合器 (AND) | fanin [hs, hf] | aggregated hf message | Q/K/V 权重矩阵 | ✅ |
| TFMLP 功能聚合器 (NOT) | fanin hf | aggregated hf message | Q/K/V 权重矩阵 | ✅ |
| GRU (AND struct) | msg, hs_old | hs_new | GRU 权重 | ✅ |
| GRU (NOT struct) | msg, hs_old | hs_new | GRU 权重 | ✅ |
| GRU (AND func) | msg, hf_old | hf_new | GRU 权重 | ✅ |
| GRU (NOT func) | msg, hf_old | hf_new | GRU 权重 | ✅ |
| MLP_prob | hf | $\hat{y}_{\text{prob}}$ | 3 层 MLP (64→32→1) | ✅ |
| MLP_rc | [hs_i, hs_j] | $\hat{y}_{\text{rc}}$ | 3 层 MLP (128→32→1) | ✅ |
| 功能距离计算 | hf_i, hf_j | $D_H(i,j) = 1-\cos(\text{hf}_i, \text{hf}_j)$ | — | ❌（无参数） |

## 5. 关键公式

### 5.1 功能距离的学习目标（论文 Equation 1-2）

$$
\text{distance}(h_i, h_j) \propto \text{distance}(T_i, T_j)
$$

- $h_i, h_j$：门 $i$ 和门 $j$ 的 embedding 向量（此处指功能嵌入 hf），$\in \mathbb{R}^{64}$
- $T_i, T_j$：门 $i$ 和门 $j$ 的真值表向量（由逻辑仿真得到），$\in \{0, 1\}^K$（$K$ 为仿真 pattern 数）
- $\text{distance}(T_i, T_j)$：归一化 Hamming 距离 = $\frac{\#\{k \mid T_i[k] \neq T_j[k]\}}{K}$

**工程直觉**：这是一个度量学习（metric learning）的目标——让 embedding 空间成为一个"保距映射"。如果两个门的真值表完全一致（Hamming 距离 = 0），它们的 hf 应该重合（cosine 相似度 = 1）。如果真值表完全相反（Hamming 距离 = 1），它们的 hf 应该正交或反向（cosine 相似度 = -1 或 0）。

### 5.2 功能距离与 embedding 距离的映射（论文 Equation 3-4）

$$
S_{(i,j)} = \text{CosineSimilarity}(h_i^f, h_j^f)
$$

$$
D_{(i,j)}^H = 1 - S_{(i,j)}
$$

$$
D_{(i,j)}^{T\prime} = \text{ZeroNorm}(D_{(i,j)}^T)
$$

$$
D_{(i,j)}^{H\prime} = \text{ZeroNorm}(D_{(i,j)}^H)
$$

$$
\mathcal{L}_{\text{func}} = \sum_{(i,j) \in N} \text{L1Loss}\left(D_{(i,j)}^{T\prime},\; D_{(i,j)}^{H\prime}\right)
$$

- $S_{(i,j)}$：功能嵌入 hf_i 和 hf_j 的 cosine 相似度，$\in [-1, 1]$
- $D_{(i,j)}^H$：embedding 空间的距离（1 - cosine 相似度），$\in [0, 2]$
- $D_{(i,j)}^T$：真值表 Hamming 距离（归一化），$\in [0, 1]$
- $\text{ZeroNorm}$：零均值归一化——将一批 pair 的距离值减去均值、除以标准差，使 embedding 距离和真值表距离具有可比尺度
- $N$：采样的 gate pair 集合，$|N| = 894,151$
- $\mathcal{L}_{\text{func}}$：功能距离损失

**为什么用 ZeroNorm 而不是直接比较**：embedding 距离（1 - cos）的范围是 [0, 2]，真值表 Hamming 距离的范围是 [0, 1]，两者尺度不同。ZeroNorm 将它们都标准化为均值为 0、标准差为 1 的分布，使 L1 loss 可以公平地比较它们。这是训练稳定性的关键设计。

**为什么考虑功能取反**：论文构造的 pair 标签中使用 $\min\text{tt\_dis}$——考虑原始真值表和取反后的真值表，取 Hamming 距离较小者。因为如果两个门的功能完全相反（如一个计算 AND，另一个计算 NAND），它们在功能上也高度相关（知道一个就能推断另一个），embedding 应该反映这种关系。通过取 min，模型学习的是"这两个门的功能有多少位一致或相反"，而不是"有多少位一致"。

### 5.3 Attention 聚合（论文 Equation 5）

$$
\alpha_j = \text{softmax}\left(\frac{(w_q^\top h_i) \cdot (w_k^\top h_j)^\top}{\sqrt{d}}\right)
$$

$$
m_j = w_v^\top h_j
$$

$$
h_i^{\text{new}} = \sum_{j \in P(i)} (\alpha_j \cdot m_j)
$$

- $\alpha_j$：fanin $j$ 对目标 gate $i$ 的 attention 权重，$\in [0, 1]$
- $w_q, w_k, w_v \in \mathbb{R}^{d \times d}$：Query/Key/Value 投影矩阵（$d=64$）
- $h_i$：目标 gate 的当前 embedding（作为 query）
- $h_j$：fanin gate 的 embedding（作为 key 和 value 的来源）
- $\sqrt{d}$：缩放因子，防止点积值过大导致 softmax 饱和
- $P(i)$：gate $i$ 的 fanin 集合
- $m_j$：fanin $j$ 的 value 投影

**为什么用 scaled dot-product attention 而非 DeepGate 的 additive attention**：scaled dot-product attention 是 Transformer 的标准做法，计算效率更高（矩阵乘法可以并行化），且 DeepGate2 在单轮传播中只对少量 fanin（AND 只有 2 个，NOT 只有 1 个）做 attention，不存在长序列的缩放问题。论文没有给出 additive vs scaled dot-product 的消融对比。

### 5.4 多任务训练损失（论文 Equation 8-12）

**Task 1: Logic Probability Prediction**

$$
\hat{P}_i = \text{MLP}_{\text{prob}}(h_i^f)
$$

$$
\mathcal{L}_{\text{prob}} = \text{L1Loss}(P_i, \hat{P}_i)
$$

- $\hat{P}_i$：预测的 signal probability，$\in [0, 1]$
- $\text{MLP}_{\text{prob}}$：3 层 MLP（64→32→1，ReLU 激活）
- $P_i$：由随机仿真得到的真实 probability

**Task 2: Reconvergence Identification**

$$
\hat{R}_{(i,j)} = \text{MLP}_{\text{rc}}([h_i^s, h_j^s])
$$

$$
\mathcal{L}_{\text{rc}} = \text{BCELoss}(R_{(i,j)}, \hat{R}_{(i,j)})
$$

- $\hat{R}_{(i,j)}$：预测 gate pair $(i,j)$ 存在 reconvergence 关系的概率，$\in [0, 1]$
- $\text{MLP}_{\text{rc}}$：3 层 MLP（128→32→1，输入是 hs_i 和 hs_j 的拼接）
- $R_{(i,j)}$：二值 ground truth（1 = 存在共同前驱，0 = 不存在）

**两阶段训练总损失**：

Stage 1:

$$
\mathcal{L}_{\text{stage1}} = \mathcal{L}_{\text{prob}} \cdot w_{\text{prob}} + \mathcal{L}_{\text{rc}} \cdot w_{\text{rc}}
$$

其中 $w_{\text{prob}}=1, w_{\text{rc}}=0$。

Stage 2:

$$
\mathcal{L}_{\text{stage2}} = \mathcal{L}_{\text{prob}} \times w_{\text{prob}} + \mathcal{L}_{\text{rc}} \times w_{\text{rc}} + \mathcal{L}_{\text{func}} \times w_{\text{func}}
$$

其中 $w_{\text{prob}}=3, w_{\text{rc}}=1, w_{\text{func}}=2$。

### 5.5 评估指标（论文 Equation 13-14）

**概率预测误差**（与 DeepGate 相同）：

$$
\text{PE} = \frac{1}{|V|} \sum_{i \in V} \left| P_i - \hat{P}_i \right|
$$

**等价门识别**：以 ROC 曲线确定最优阈值 $\theta$，然后计算：

$$
\text{TP} = \frac{\sum ((D_{(i,j)}^T = 0) \land (S_{(i,j)} > \theta))}{M}
$$

$$
\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}},\quad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}},\quad \text{F1} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
$$

| 训练要素 | 具体设置 |
|----------|----------|
| 数据集 | 与 DeepGate 相同：10,824 个 AIG 子电路，构造 894,151 个 gate pair |
| 数据划分 | 80/20 训练/测试（按 circuit 划分，避免节点泄漏） |

| hs/hf 维度 | 各 64 维 |

### 6.2 监督信号怎么造出来

DeepGate2 的监督信号比 DeepGate 复杂得多，分三个层级：

**Level 1: 单门 signal probability（与 DeepGate 相同）**
- 15,000 个随机 pattern 仿真，统计每个门输出为 1 的频率

**Level 2: gate pair 真值表 Hamming 距离（DeepGate2 新增）**
- 对 PI 数量 ≤ 13 的电路：枚举完整真值表 ($2^{\text{PI}}$ 种输入组合)
- 对 PI 数量 > 13 的电路：采样 15,000 个随机 pattern（但 paper 中说"incomplete truth table with 15,000 random patterns"）
- 按 4 个约束条件采样 pair（共享 PI、概率接近、层级接近、Hamming 距离极端）
- 对每个 pair 计算归一化 Hamming 距离和考虑取反后的 min Hamming 距离

**Level 3: reconvergence pair 标签**
- 扫描电路 DAG，标记哪些 gate pair 存在共同前驱（common predecessor）

### 6.3 实验设置

**Baseline 对比**：
- DeepGate（ICCAD 2022 前身，signal probability 监督 + 多轮传播）
- FGNN（功能感知的对比学习 baseline，通过电路扰动生成正负样本对）

**评估电路**：10 个工业电路（D1~D10），规模从 3,183 门到 40,496 门。

**下游任务设置**：
- **SAT Sweeping**：DeepGate2 作为 ABC `&fraig` 的插件，用 embedding 相似度排序等价类候选，优先检查最可能等价的 gate pair。6 个工业电路，单核 CPU，<1GB 内存。
- **SAT Solving**：DeepGate2 嵌入 CaDiCal SAT 求解器，用功能相似度指导变量决策——如果两个变量功能高度相似，对其中一个赋值时立即对另一个赋相反值以触发冲突学习。5 个 LEC instance，规模 17,495~28,672。

**主实验一：概率预测 + 速度（论文 Table I）**

|------|---------:|----------:|-----:|
| 平均 PE | 0.0356 | **0.0310** | 降低 13.08% |

**这张表说明什么**：DeepGate2 在"更快"和"更准"两个维度上同时超越 DeepGate。这不是一个 trade-off（牺牲精度换速度），而是通过 PI Encoding + 单轮传播的架构改进实现了全面的帕累托改进。16.43 倍的加速来自将 10 轮正向 + 10 轮反向传播压缩为 1 轮正向传播——传播次数减少 20 倍，但实际加速比略低于 20 倍因为单轮传播中每个 gate 需要维护两套 embedding。

**主实验二：等价门识别（论文 Table II）**

| 模型 | Recall | Precision | F1-Score |
|------|-------:|----------:|---------:|
| FGNN | 59.11% | 36.60% | 0.4402 |

**这张表说明什么**：三层次的功能感知能力递增。FGNN 通过对比学习（扰动电路生成正负样本）学功能，但它依赖结构相似性作为捷径（扰动小的电路结构相似 → 被误判为功能等价），导致极低的 Precision（36.60%）。DeepGate 有了更好的 Recall（91.46%），因为 signal probability 能筛掉大部分不相关的 pair，但 Precision 只有 54.00%——概率相同但功能不同的 pair 被大量误判为等价（论文进一步分析：80.83% 的假阳性来自概率相同但功能不同的 pair）。DeepGate2 用 Hamming 距离直接监督功能关系，Recall 提升到 98.73%（几乎不漏）且 Precision 提升到 90.49%（大幅减少误判）。0.9434 的 F1 意味着这个任务基本上被解决了。

## 7. 创新点

### 创新点 1：pairwise truth-table Hamming distance 监督——从统计量到结构量

这是 DeepGate2 最核心的贡献。DeepGate 的 signal probability 只问"1 有多少个"（一个统计量），DeepGate2 的 pairwise Hamming distance 问"哪些位置上的 1 相同"（一个结构量）。

具体的函数区分案例（论文 Figure 2）：

```text
  3 个 PI，共 8 种输入组合:

  电路 A: output = [0,1,1,0,1,1,1,1]  logic-1 概率 = 6/8 = 0.750
  电路 B: output = [1,0,0,1,1,1,1,1]  logic-1 概率 = 6/8 = 0.750
  电路 C: output = [0,1,1,0,1,1,1,1]  logic-1 概率 = 6/8 = 0.750  (≡ A)
  电路 D: output = [0,0,0,0,1,1,1,1]  logic-1 概率 = 4/8 = 0.500

  DeepGate 视角: A≈B≈C,  D 不同 (只看概率)
  DeepGate2 视角: A≡C (0 bit diff), A~B (2 bit diff), A≠D (5 bit diff)
```

DeepGate2 的 embedding 空间中，距离关系是：$D(A,C) < D(A,B) < D(A,D)$。这是功能感知的表征——不是"你们概率都是 0.75 所以你们差不多"，而是"你们真值表的每一行具体有哪些异同"。

### 创新点 2：hs/hf 双分支解耦 + PI Encoding——一次解决两个深层缺陷

DeepGate 有两个深层缺陷：(a) 所有 PI 初始 embedding 相同 → 无法区分 PI 身份 → 必须多轮传播来间接发现 reconvergence；(b) 结构和功能信息纠缠在同一个向量里 → 无法解耦"怎么连"和"算什么"。

DeepGate2 用两个互补设计一次性解决：
- **PIE** 解决了 (a)：PI 有唯一正交 hs → 单轮即可捕获 reconvergence
- **hs/hf 解耦** 解决了 (b)：结构分支专注于位置编码，功能分支专注于布尔行为，两者通过 [hs, hf] 拼接在功能聚合器中交汇——hs 为 hf 提供结构上下文，但不干预 hf 的功能语义

### 创新点 3：One-round GNN——用架构设计替代计算

不需要增加参数量，不需要更深的网络，只需要改变初始化和传播策略，就从 20 轮降到 1 轮，同时精度还提升了。这证明了 DeepGate 的多轮传播不是"功能需要"而是"设计缺陷的补丁"——一旦 PI 身份问题被 PIE 解决，一轮就足够了。

### 创新点 4：从表示学习到工具集成——让 embedding 真正驱动 EDA 加速

DeepGate 止步于"学到 embedding，展示预测误差"。DeepGate2 前进了两步：(a) 在逻辑综合工具 ABC 中实际部署，用 embedding 相似度引导 SAT sweeper 的等价类选择优先级；(b) 在 SAT 求解器 CaDiCal 中嵌入功能相似度信息，指导变量决策。这是在真实 EDA 工作流中验证 AI 方法价值的正确姿势——不仅证明"我学到了更好的表示"，还证明"这个更好的表示能让你少跑 95% 的 SAT 调用"。

### 创新点 5：Two-stage curriculum learning 应对多任务训练的不稳定性

同时优化三个性质差异巨大的损失（概率 L1、reconvergence BCE、功能距离 L1）会导致训练不稳定——功能距离损失在没有好的 hf 时提供的梯度近乎噪声。两阶段策略（先学简单的概率，再学复杂的 pair 比较）解决了这个问题。消融证明 single-stage 训练会导致 F1 暴跌 20 个百分点。

| PIE | PI Encoding | DeepGate2 为不同 PI 分配正交初始结构向量的策略，是实现单轮传播的关键 |
| TFMLP | Transformer-style MLP | DeepGate2 的消息聚合器：用 Q/K/V scaled dot-product attention 对 fanin 加权求和 |
| hs / hf | Structural / Functional embedding | DeepGate2 的双分支隐状态——hs 编码连接关系，hf 编码布尔行为 |
| Hamming Distance | 汉明距离 | 两个等长二进制串中不同位的个数。DeepGate2 用它比较真值表差异 |
| SAT Sweeping | — | 逻辑综合中的冗余门消除技术：通过 SAT 求解证明两个门等价后合并，减少网表面积 |
| LEC | Logic Equivalence Checking | 形式验证的核心任务：证明两段电路在所有输入下输出完全相同 |
| CaDiCal | — | 一个现代 CDCL（Conflict-Driven Clause Learning）SAT 求解器 |
| `&fraig` | — | ABC 工具中基于 SAT 的功能化简命令，DeepGate2 作为其插件部署 |
| BCE | Binary Cross-Entropy | 二分类交叉熵损失。DeepGate2 用它训练 reconvergence 识别 |
| Multi-stage Training | 多阶段训练 | 先学简单任务（Stage 1: 仅概率），再加入复杂任务（Stage 2: +功能距离）的课程学习策略 |
| ZeroNorm | — | 零均值归一化：减去均值除以标准差，使不同尺度的距离度量为可比 |
| FGNN | Functionality-aware GNN | DeepGate2 的对比学习 baseline：通过电路扰动生成正负样本对，训练模型区分功能等价/不等价 |

其他缩写（AIG / PI / PO / DAG / GNN / GRU / SAT / L1 / ROC / AUC 等）见 [DeepGate 论文深度讲解](../DeepGate/论文深度讲解.md) 第 8 节。

## 9. 与芯片流程的关系

### 9.1 在全流程中的位置

```text
  ③ 逻辑综合
       │
       ├──→ 综合输出: AIG 网表
       │         │
       │         ▼
       │    ┌─────────────────────────────┐
       │    │  DeepGate2 推理              │
       │    │  → hs/hf embedding           │
       │    │  → gate pair 功能相似度       │
       │    └──────────┬──────────────────┘
       │               │
       │    ┌──────────┴──────────────────┐
       │    │                             │
       │    ▼                             ▼
       │  SAT Sweeper                  SAT Solver
       │  (ABC &fraig)                (CaDiCal)
       │  embedding 排序 EC 候选      功能相似度指导
       │  优先检查高相似度 pair       变量决策
       │  SAT 调用 -53%              求解时间 -40%
       │               │
       │               ▼
       └──→ 优化后的 AIG 网表 (冗余门已合并)
                │
                ▼
           ④ 门级仿真 → ⑤ STA → ⑥ 形式验证 → ...
```

DeepGate2 与 DeepGate 的关键差异：DeepGate 在流程中是"一个提供 embedding 的组件"，DeepGate2 是"一个嵌入 EDA 工具链并改变其行为的系统"。它的 embedding 不只是输出给人类看，而是直接作为下游工具（ABC、CaDiCal）的决策输入，产生了可量化的运行时收益。

### 9.2 「等价门识别 F1=0.9434」和「芯片可靠」之间隔着什么

DeepGate2 的等价门识别在论文的 10 个工业电路上取得了令人印象深刻的 F1-score，但距离"可以在真实流片中依赖"仍有距离：

**差距 1：假阴性（漏判等价对）的风险**。Recall 98.73% 意味着约 1.27% 的真实等价 pair 被漏判。在逻辑综合中，漏判等价门只是多保留几个冗余门（面积略大），不会导致功能错误。但在形式验证中，如果把漏判的等价 pair 误认为需要进一步证明，会增加 SAT solver 的不必要调用——虽不致命但浪费资源。

**差距 2：假阳性（误判等价对）的致命性**。Precision 90.49% 意味着约 9.51% 的判为等价的 pair 实际上功能不等价。在 SAT sweeping 中，假阳性会被后续的 SAT 求解器（`&cec` 命令）拦截——SAT solver 会返回一个反例（counterexample），证明这两个门不等价，然后 sweeping manager 用这个反例修正等价类。所以**在论文的流程中，假阳性不会导致功能错误**——它只会导致一个 SAT solver 调用去"纠正"这个错误。但如果 DeepGate2 用于直接指导门合并（不经过 SAT 验证），假阳性将导致功能错误——把不等价的门当成等价的合并了，芯片行为就不对了。

**差距 3：真值表采样的局限性**。15,000 个随机 pattern 对于 PI=128 的电路（$2^{128}$ 种输入），覆盖率约 $15000/2^{128} \approx 4.4 \times 10^{-35}$。两个真值表在随机 15,000 个 pattern 下恰好相同，不一定意味着它们在所有 $2^{128}$ 种输入下完全相同。虽然概率极低，但理论上的假阳性风险存在。

## 10. 讨论与局限

### 10.1 论文自述的局限

论文在 conclusion 中未显式列出局限，但从方法和实验边界可以推断：
1. **仅限组合逻辑**：AIG 不含时序单元，DeepGate2 无法处理 DFF/clock/reset
2. **pair 采样策略限制了功能监督的覆盖面**：只采样逻辑概率接近 + 层级接近的 pair，意味着"概率不同但功能相关的 pair"（如一个信号和它的取反）不会被显式监督。虽然 min_tt_dis 考虑了取反，但 pair 采样阶段就把这类 pair 筛掉了
3. **PI 数量 > 13 时用的是不完整真值表**：Harming 距离在有限采样下的近似误差未被量化

### 10.2 代码/复现层面的问题

从 [DeepGate2论文与本地复现详解.md](./DeepGate2论文与本地复现详解.md) 提炼：

| 项目 | 论文/期望 | 代码实际 | 影响 |
|------|----------|---------|------|
| Checkpoint | 应含 Stage 1/Stage 2 权重 | 无预训练 checkpoint 发布 | 无法直接使用论文训练的模型 |
| 训练数据 | 10,824 AIG + 894K pairs | 未随代码发布 | 复现需自行从 benchmark 重新生成 |

| 文档拼写 | — | `stage2_trun.sh`（应为 `train`） | 无功能影响 |

本地已完成最小 13 节点 smoke test（171,334 参数，成功输出 hs/hf/prob/rc），但未完成论文规模的训练和评测。

### 10.3 本资料包的批判性分析

**"单轮传播"是否真的等价于"20 轮传播的信息量"？** DeepGate2 的核心声称是"1 轮 > 20 轮"，但这个声称需要限定条件。PIE 让 PI 身份在初始化时就被编码，这替代的是"发现 PI 身份"的传播需求。但电路中的长程依赖（一个信号从 level 0 的 PI 经过 50 层逻辑到达 level 50 的 PO）仍然需要通过逐层传播来传递信息——PIE 没有解决这个问题，只是 level-wise 单轮传播在 DAG 中已经自然覆盖了所有路径长度。

**pair 采样的标签泄漏风险**：DeepGate2 的 pair 采样约束之一是"两个 gate 共享同一组 PI"——这确保了比较的公平性。但如果训练集和测试集是按 circuit 划分的，每个 circuit 内的所有 pair 都在同一集合中，不存在跨 circuit 的 pair 泄漏。关键是 paper 的"80/20 split"是否真的是按 circuit 划分？论文说"按整个 circuit 划分"，但未公开 split manifest，无法独立验证。

**从 F1=0.9434 到 SAT sweeping 的因果关系**：论文展示了 DeepGate2 的 embedding 能加速 SAT sweeping，但没有做消融实验来证明"是功能感知的 embedding（而非单纯的概率预测）导致了加速"。一个可能的替代假说是：仅仅概率预测 + 简单的启发式规则（"概率相同的 pair 优先检查"）也能获得类似的 SAT sweeping 加速效果。这是需要在后续工作中验证的。

**为什么 D10（最大电路，40K 门）的 F1 仍然很高？** D10 的 F1=0.9283，说明 40K 门规模下功能感知没有显著退化。但论文测试的最大电路只有 40K 门，从 40K 到 1M+ 门的扩展性仍然未知。特别是 pair 数量以 $O(N^2)$ 增长，在 1M 门电路上构造 pair 和计算功能距离需要的计算和存储资源将是巨大的。

## 12. 一分钟复述版

DeepGate2（CUHK + 宁波大学 + 华为诺亚方舟，ICCAD 2023）是 DeepGate 的功能感知升级。核心发现：DeepGate 的 signal probability 监督分不清"概率相同但功能不同"的门（如 AND(a,b) 和 AND(b,a) 在 PI 均匀分布下概率相同），且所有 PI 初始 embedding 相同导致必须多轮传播。

三个核心改进：(1) 用 pairwise truth-table Hamming distance 替代 signal probability 作为功能监督——直接比较两个门在采样 pattern 下的输出差异位数，使 embedding 空间的距离正比于功能差异；(2) 将每个门的 embedding 拆为 hs（结构，编码"怎么连"）和 hf（功能，编码"算什么"），hs 给 attention 提供结构上下文，hf 负责功能距离学习；(3) 给每个 PI 分配唯一正交初始 hs 向量（PI Encoding）——PI 身份在初始化时就被区分，不需要多轮传播来间接发现。

结果：概率预测误差降 13.08%（0.0356 → 0.0310），推理速度提升 16.43 倍（59s → 3.6s），等价门识别 F1 从 0.6778 跃升至 0.9434。下游真实 EDA 工具收益：ABC SAT sweeping 的 SAT 调用减少 53.37%（最大 95.88%），CaDiCal SAT 求解器在 LEC instance 上平均加速 40.05%。

局限：仍限于组合逻辑（无 DFF/clock）；pair 采样约束（只选概率接近 + 层级接近的 pair）可能遗漏功能相关但概率不同的 cases；PI 多时用 15K pattern 近似 Hamming 距离；训练数据和 checkpoint 未发布。

## 13. DeepGate → DeepGate2 升级了什么

这是从"结构相似"到"功能感知"的范式升级。以下是逐条对比：

### 升级 1：监督信号——从统计量到结构量（动机：结构不同但功能相同的电路，DeepGate 会给出不同 embedding）

| 维度 | DeepGate | DeepGate2 |
|------|----------|-----------|
| 监督信号 | 单门 signal probability $P(v=1)$ | 门对 truth-table Hamming distance |
| 信息类型 | 统计量（1 的个数比例） | 结构量（具体哪些 pattern 输出不同） |
| 能否区分同概率不同功能的门 | ❌ AND(a,b) 和 XOR(a,b) 在 PI 概率 0.5 时都是 0.5 | ✅ Hamming 距离直接反映功能差异 |
| 本质 | "这个门输出 1 的概率是 75%" | "这两个门的真值表有 2/8 位不同" |

**为什么这对下游任务是错的**：在形式验证（等价性检查）中，你需要知道"门 A 和门 B 是否功能等价"——这不是概率问题，是真值表问题。DeepGate 把两个概率相同但功能不同的门映射到相近的 embedding，导致等价性判断失效。论文数据：DeepGate 在等价门识别上 Precision 仅 54.00%，其中 80.83% 的假阳性来自"概率相同但功能不同"的 pair。

### 升级 2：embedding 结构——从单向量到双分支解耦

| 维度 | DeepGate | DeepGate2 |
|------|----------|-----------|
| embedding 数量 | 每个门 1 个 h (64 维) | 每个门 2 个: hs + hf (各 64 维) |
| 结构信息 | 与功能信息混在一起 | hs 独立编码 |
| 功能信息 | 与结构信息混在一起 | hf 独立编码，但聚合时接收 hs 作为上下文 |
| PI 初始状态 | 所有 PI 相同初始 embedding | hs 正交（唯一身份），hf 共享（概率相同） |

**为什么需要解耦**："你连到谁"和"你算什么"是两个不同性质的问题。一个 AND 门的位置（在 level 3，fanin 来自 PI_a 和 PI_b）是结构事实，它的功能（a & b）是逻辑事实。两者有因果关系（位置决定了哪些 PI 影响它），但不应该被压缩到同一个向量里——这会让模型难以学习"两个位置不同但功能相同的门应该功能相似"（如两个不同位置的 2 输入 AND 门）。

### 升级 3：传播效率——从 20 轮到 1 轮

| 维度 | DeepGate | DeepGate2 |
|------|----------|-----------|
| 传播方向 | 10 轮正向 + 10 轮反向 | 1 轮正向 |
| 为什么需要多轮 | PI 身份靠多轮传播间接区分 | PI 身份在初始化时已区分（PIE） |
| 推理时间（平均） | 59.04s | 3.59s |
| 加速比 | 1x | **16.43x** |
| 反向传播 | 有（捕获逻辑蕴涵） | 无（PIE 替代了反向传播的信息获取） |

### 升级 4：训练策略——从单任务到多任务课程学习

| 维度 | DeepGate | DeepGate2 |
|------|----------|-----------|
| 训练任务 | 1 个（概率回归） | 3 个（概率 + reconvergence + 功能距离） |
| 训练阶段 | 单阶段 60 epochs | 两阶段：先学概率（Stage 1），再加入 pair 监督（Stage 2） |
| 为什么分阶段 | 不需要（只有一个任务） | 防止功能距离损失在 hf 未收敛时提供噪声梯度 |

### 升级 5：下游验证——从"能做"到"做了并加速"

| 维度 | DeepGate | DeepGate2 |
|------|----------|-----------|
| 下游评估 | 概率预测误差 + 泛化 | 概率预测 + 等价门识别 + SAT sweeping + SAT solving |
| EDA 工具集成 | 无 | ABC `&fraig` 插件 + CaDiCal 嵌入 |
| 运行时收益 | 无量化 | SAT calls -53%, SAT sweeping runtime -49%, SAT solving -40% |

### 实测下游任务收益汇总

| 下游任务 | DeepGate | DeepGate2 | 提升 |
|----------|---------:|----------:|-----:|
| 等价门识别 F1 | 0.6778 | **0.9434** | +39.2% |
| 等价门识别 Precision | 54.00% | **90.49%** | +67.6% |
| SAT sweeping SAT calls | baseline | **-53.37%** | — |
| SAT solving (LEC) | baseline | **-40.05%** | — |
