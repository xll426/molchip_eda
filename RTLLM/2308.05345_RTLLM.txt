                                                                       whether the design can be correctly synthesized into netlist

                                                                          After ensuring syntax correctness, we name the second
                                                                       goal as the functionality goal. It means the functionality of
                                                                       generated RTL design V should be exactly the same as the

                                                                       the generated design passes all test cases in a comprehensive
                                                                       testbench. Of course, exhausting all possible test cases will
                                                                       make the testbench file extremely cumbersome. Our bench-
                                                                       mark only samples a reasonable number of test cases. Passing
                                                                       all test cases does not necessarily mean the functionality is
                                                                       100% correct.

                                                                       and functionality, the design can be viewed as successful. But
